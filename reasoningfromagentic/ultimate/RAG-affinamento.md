## 1.1 — Document Segmentation Logica

Introduce un passo **pre-chunking** che separa documenti multi-procedura prima che il `SemanticChunker` agisca.[](https://ppl-ai-file-upload.s3.amazonaws.com/web/direct-files/attachments/130566781/d9ecd23a-2acb-492d-88a4-da1fca3845c3/tenderwriter2.md)

python

`# Aggiunto in ingestion_pipeline.py PRIMA di chunk_and_embed() def segment_by_procedure(raw_text: str, tender_id: int) -> list[dict]:     """    Separa sezioni logiche autonome (es. Capitolato A vs Capitolato B)    usando heading detection + boundary heuristics.    """    segments = []    boundaries = detect_section_boundaries(raw_text)  # regex su titoli H1/H2    for seg in boundaries:        segments.append({            "text": seg.text,            "procedure_label": seg.title,            "page_range": seg.pages,            "tender_id": tender_id        })    return segments`

Questo risolve il problema documentato del PDF Toscana (due gare → un solo spazio vettoriale): ciascuna procedura diventa uno **spazio semantico isolato** in Qdrant (collection separata o payload filter).[](https://zilliz.com/it/blog/enhance-rag-with-knowledge-graphs)[](https://ppl-ai-file-upload.s3.amazonaws.com/web/direct-files/attachments/130566781/d9ecd23a-2acb-492d-88a4-da1fca3845c3/tenderwriter2.md)

## 1.2 — Identity Hash su Requirement per Neo4j

Prima di ogni `MERGE` su Neo4j, calcola un fingerprint deterministico:[](https://ppl-ai-file-upload.s3.amazonaws.com/web/direct-files/attachments/130566781/d9ecd23a-2acb-492d-88a4-da1fca3845c3/tenderwriter2.md)

python

`import hashlib, unicodedata def compute_requirement_hash(text: str, tender_id: int) -> str:     normalized = unicodedata.normalize("NFKD", text.strip().lower())    return hashlib.sha256(f"{tender_id}::{normalized}".encode()).hexdigest()[:16]`

Questo `identity_hash` diventa la chiave di upsert:

text

`MERGE (r:Requirement {identity_hash: $hash}) ON CREATE SET r.text = $text, r.created_at = timestamp() ON MATCH  SET r.text = $text, r.updated_at = timestamp()`

Elimina la proliferazione di nodi duplicati su re-ingestione e rende il grafo deterministico.[](https://www.databricks.com/it/blog/building-improving-and-deploying-knowledge-graph-rag-systems-databricks)[](https://ppl-ai-file-upload.s3.amazonaws.com/web/direct-files/attachments/130566781/d9ecd23a-2acb-492d-88a4-da1fca3845c3/tenderwriter2.md)

`MAX_ITERATIONS   = 4 MAX_TOKENS_TOTAL = 8_000   # per query su Gemma 4 31b FALLBACK_CHAIN   = ["react_full", "tools_only", "rag_standard", "insufficient_evidence"] async def run_react_loop(query, tools, budget):     iterations, tokens_used = 0, 0    while iterations < MAX_ITERATIONS and tokens_used < budget:        thought = await llm.think(query, history)        tool_call = parse_tool_call(thought)        if tool_call is None:            break  # LLM ha risposto direttamente        result = await tools.execute(tool_call)        tokens_used += count_tokens(thought, result)        iterations += 1    return synthesize(history)`
