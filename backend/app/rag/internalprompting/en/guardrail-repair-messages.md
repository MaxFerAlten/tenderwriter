# Guardrail Repair Messages (EN)

Replacement strings used by `procedure_guardrails.repair_*` to mask
unverified values and to build narrative fragments when the guardrail swaps
unsupported claims with verified facts pulled from the fact sheet.

## Messages

unverified_procedure_id: unverified procedure ID
unverified_cig: unverified CIG
unverified_amount: unverified amount
unverified_term: unverified term
unverified_days: unverified days
unverified_duration: unverified duration
unverified_percentage: unverified percentage
unverified_location: unverified location
unverified_article: unverified article
fragment_procedure_id_label: Procedure ID
fragment_cig_label: CIG
fragment_duration_label: duration
fragment_amounts_label: amounts
fragment_locations_label: locations
verified_data_intro: Verified data
distinct_amounts_template: with distinct values equal to {low} and {high}
blocked_output: output blocked: conflict or unverified data
unit_days: days
unit_months: months
unit_years: years
conjunction_and: and
