# Engine Language Detection Markers (IT)

Marker usati da `_retrieval_variant_language_for` per scegliere la variante
di retrieval (it/en) basata sui token nella query. Entrambi i set sono
intrinsecamente cross-linguali (servono a confrontare presenza di parole
italiane contro inglesi nella stessa query) quindi le sezioni sono
identiche tra `it/` ed `en/`.

## Italian Markers

- gara
- bando
- capitolato
- disciplinare
- procedura
- panoramica
- riassum
- sintetizz
- spiega
- descriv
- analizz
- punti chiave
