Mix Architecture for TenderClaw

This directory holds high-level architectural guidance and starter scaffolding for porting TenderClaw towards a true multi-plane runtime. The aim is to move from a web orchestrator to a six-plane architecture and to anchor the porting plan to concrete file targets.

- Architecture overview (six planes) documented in architecture.md
- Starter parity matrix generator (parity_matrix.py)
- Parity matrix templates and example plans (parity_matrix_template.md)

Note: This is intentionally lightweight and designed to be extended as we port more components.
